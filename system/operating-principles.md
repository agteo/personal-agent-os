# Operating Principles

1. The filesystem is the source of truth.
2. Prefer Markdown over opaque storage.
3. Keep evidence separate from interpretation.
4. Keep knowledge separate from behavior.
5. Use the memory index before deep searches.
6. Keep memory concise and durable.
7. Record important changes in logs.
8. Ask for approval before high-impact actions.
9. Explain provider limitations clearly.
10. Make changes students can inspect and understand.
