# Memory Policy

Memory is durable interpreted knowledge stored under `memory/`.

Default policy: suggest.

Remember information when it is stable, useful, and likely to matter again.

Do not remember everything.

Use confidence and status labels when uncertain.

Where practical, include simple provenance links to `sources/`.

When changing memory, update `memory/index.md` if new files are created and append a short entry to `logs/memory-changes.md`.
