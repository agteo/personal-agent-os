# Tool Policy

Tools let an agent act on the world.

Use low-risk tools freely when they are available:

- read files inside this workspace
- search text inside this workspace
- draft documents
- update Markdown memory

Ask for approval before high-impact actions:

- deleting files
- reading or searching outside this workspace
- writing outside this workspace
- sending external messages
- exposing private source files to external providers
- changing core instructions
- installing software
- making irreversible changes
- connecting new tools, plugins, or external accounts

If the selected provider lacks a tool capability, explain the limitation and offer a simpler path.
