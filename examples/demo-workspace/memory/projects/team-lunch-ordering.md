# Team Lunch Ordering

## Summary

Team Lunch Ordering is a workplace project exploring how to make group meal ordering faster and clearer for hybrid teams.

## Current Goals

- Reduce ordering confusion during busy workdays.
- Help employees see pickup or delivery timing before paying.
- Improve accessibility for people with dietary restrictions.

## Status

Active

## Important Decisions

- Use a checkout flow that shows pickup or delivery time before payment.

## Open Questions

- Should dietary filters be part of search, checkout, or both?
- How much menu detail is needed before the interface feels cluttered?
