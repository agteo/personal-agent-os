# Campus Food App

## Summary

Campus Food App is a student project exploring how to make campus meal ordering faster and clearer.

## Current Goals

- Reduce ordering confusion during lunch rush.
- Help students see pickup timing before paying.
- Improve accessibility for students with dietary restrictions.

## Status

Active

## Important Decisions

- Use a checkout flow that shows pickup time before payment.

## Open Questions

- Should dietary filters be part of search, checkout, or both?
- How much menu detail is needed before the interface feels cluttered?
