# Skills

A skill is a Markdown instruction file that teaches the agent how to perform a reusable task.

To create a new skill:

1. Copy an existing skill folder.
2. Rename it.
3. Edit `SKILL.md`.

Skills should be understandable without writing Python.

Common sections:

- Purpose
- When to use
- Inputs
- Process
- Output
- Memory behaviour
- Capability requirements
