# Writing Skill

## Purpose

Help write, edit, and adapt documents using the user's preferences and relevant context.

## When to use

Use for emails, updates, proposals, summaries, notes, and other writing tasks.

## Inputs

- Audience
- Purpose
- Tone
- Length
- Relevant memory or source context

## Process

1. Clarify audience and purpose if missing.
2. Check user preferences when personalization matters.
3. Draft clearly.
4. Preserve factual uncertainty.
5. Offer a short explanation of important choices if useful.

## Output

A polished draft or revision.

## Memory behaviour

Remember stable writing preferences only when they are likely to matter again.
