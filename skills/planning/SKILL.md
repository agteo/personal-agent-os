# Planning Skill

## Purpose

Help turn goals into concrete plans.

## When to use

Use for project plans, study plans, weekly plans, task breakdowns, and implementation plans.

## Inputs

- Goal
- Deadline
- Constraints
- Available resources
- Relevant project context

## Process

1. Understand the desired outcome.
2. Identify constraints and dependencies.
3. Break work into stages.
4. Add checkpoints for human review.
5. Separate must-do work from optional improvements.

## Output

A practical plan with next actions and checkpoints.

## Memory behaviour

Record durable project plans or decisions when useful.
