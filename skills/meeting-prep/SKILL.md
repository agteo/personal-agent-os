# Meeting Prep Skill

## Purpose

Prepare the user for a meeting using memory, sources, and known project context.

## When to use

Use when the user asks for meeting preparation, briefing notes, talking points, or context before a meeting.

## Inputs

- Meeting name or topic
- Date and time if known
- Attendees if known
- Related project

## Process

1. Identify the likely project, people, and decisions involved.
2. Read `memory/index.md`.
3. Read relevant project, people, and decision memory.
4. Review related source notes if useful.
5. Identify open questions, risks, decisions, and suggested talking points.
6. Keep the briefing concise.

## Output

A practical meeting brief with context, goals, open questions, and suggested next actions.

## Memory behaviour

After the meeting, ask whether there are new decisions or updates to record.
